# 外参自动标定（版本 1：普通棋盘格）操作说明

适用于现在使用普通棋盘格的实验。整个流程是：算法自动找角点，操作者确认原点并校阅，通过后再生成标定。

## 操作步骤（Calibration → Corners & run）

1. 照常为每台相机采集外参帧。相机的 `extrinsics/camNN/` 文件夹里放几张静态帧或一段短视频都可以，帧越多越稳。
2. 点 **⚡ Auto-detect ALL cameras**，所有相机会自动检测。日志会显示每台相机在几帧里找到了板。
3. 逐台相机检查：
   - **绿色点是原点（0 号角点）**，必须在每台相机上都是同一个物理角。
   - 位置正确就点 **✓ Origin OK**；不正确就点 **Set origin…**，再点一下正确的那个角，程序会重新编号。
   - 第一台确认之后，程序会记住原点方格是深色还是浅色，后面的相机通常能自动放对。
   - 个别角点不准时可以直接拖动微调（勾选 "Snap clicks to corner" 后松手会自动吸附）。
   - 点 **Save corners for this cam**。
4. 自动检测没找到板的相机，用 **4-corner mode…**：按任意顺序点最外圈的 4 个内角点，其余角点会自动补齐并吸附。
5. 点 **▶ Run calibration**。如果还有相机的原点没确认，程序会拒绝运行并列出这些相机。
6. 运行完成后会弹出评估结果：
   - 全部绿色：在 Verify 页看一眼立方体就可以结束。
   - 有黄色或红色：按提示到对应相机微调角点，保存后重新运行。

## 红黄绿阈值（初始值，会根据合作机构的数据调整）

| 指标 | 绿 | 黄 | 红 |
| --- | --- | --- | --- |
| 单相机 / 多相机重投影误差 | < 0.5 px | 0.5–1.5 px | > 1.5 px |
| 三角化后方格边长误差 | < 1% | 1–3% | > 3% |
| 三角化后板的平整度 | < 2 mm | 2–5 mm | > 5 mm |

## 留痕

每台相机的 `points.json` 会记录角点来源（auto / four / adjusted / manual）、原点是否经过确认、保存时间。旧项目里手点保存的角点没有这些记录，会被视为已确认，可以照常使用。

## 已知限制

- 相机位置很低、板几乎贴着视线（俯视角小于约 20°）时，方格在画面里会被压得很扁，自动检测会失败，需要用 4-corner mode。
- 推断原点用的是"相机从上方俯视地面上的板"这个假设。如果板是竖着放的，请每台相机都手动确认原点。
- 板的内角点数一奇一偶（例如 5×8）时，才能按颜色自动推断原点；两个都是偶数或都是奇数时，只能每台手动确认。
